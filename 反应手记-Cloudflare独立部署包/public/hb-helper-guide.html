测试后回填，核实后保存。

适用于电脑 Edge / Chrome。首次安装助手后，从反应手记发起测试，最终平均成绩会返回待核实草稿。

下载回填助手 ZIP

首次设置

  1. 下载 ZIP，解压到一个保留使用的文件夹。
  2. 在 Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。
  3. 开启“开发人员模式”，选择“加载解压缩的扩展”，选中包含 manifest.json 的文件夹。
  4. 允许助手访问 Human Benchmark 和反应手记，然后刷新记录页。

记录页出现“回填助手已连接”后，即可使用。不需要安装 GitHub skill。

每次怎么用

  1. 在记录页选好活动、时长等情况。
  2. 点击页面顶部“Human Benchmark 测试”，保留原记录页。
  3. 完成一组 5 次测试。助手只读取最终平均成绩，保留 Human Benchmark 显示的四舍五入结果。
  4. 回到记录页核对成绩和时间，勾选确认，再点击“核实后保存这次测试”。

每一组请从记录页重新点击测试链接；同一测试页的 Try again 不会再次回填。已有成绩草稿时，会先询问是否替换。正在编辑历史记录、切换了账号或刷新了记录页时，旧测试不会直接覆盖表单；请重新从记录页发起。

权限与使用范围

这是本项目提供的本地扩展，限定访问这两个网站。它不代你点击测试，不读取账号密码，不自动保存记录，也不上传成绩到其他服务。只有你点击保存后，网站才按原来的规则保存和同步。

助手仅关联从记录页发起的测试，不扫描其他标签页。更新助手时，替换解压文件后在扩展管理页点击重新加载；随后刷新记录页。

如果 Human Benchmark 改了结果页面结构，助手会停止识别，仍可手动录入。不支持电脑以外浏览器的安装保证。
