# 反应手记成绩回填助手（电脑 Edge / Chrome）

此助手只读取从 https://reaction-diary.warm1ng.workers.dev/ 发起的 Human Benchmark 反应测试最终成绩。它不会点击测试区域，不会保存记录，不读取账号密码，不上传成绩到其他服务。

## 安装一次

1. 将助手 ZIP 解压到一个固定文件夹，保留文件夹，以后不要移动或删除。
2. Edge 地址栏打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”，选择**直接包含 manifest.json 的文件夹**。
4. 确认助手已启用，然后刷新反应手记页面。

不需要安装 GitHub skill、油猴或其他扩展，也不需要提供密码或 Cloudflare 授权。

## 使用

1. 在反应手记填写/选择当前情况，从页面里的 Human Benchmark 链接发起。
2. 完成一组 5 次有效反应测试。助手只读取最终结算页面显示的平均成绩（Human Benchmark 显示值已经取整）。
3. 助手把成绩带回原记录页的待核实草稿并切回记录页；Human Benchmark 标签页保留，可以切过去核对。
4. 在反应手记核对成绩，再按网页要求确认并点击保存。

直接从收藏夹进入 Human Benchmark 不会建立回填关联。需要开始新一组时，请回反应手记再次点击链接；每次发起只回填一个最终结果。

## 防止误录

- 不读取每次点击后的单次成绩，只读取 `[data-test].view-score` 最终页面的一个 h1 成绩。
- 旧测试页、重复发送、另一个记录页、账号/日期变化、记录页刷新或关闭，都不能覆盖当前表单。
- 记录页已有成绩时，由网页提示是否采用新成绩；不会自动替换或自动保存。
- Human Benchmark 页面结构变化时，助手可能停止识别。此时请手动填写；不会改为从整个页面猜一个数字。
- 页面翻译通常不影响识别；若 ms 被翻译成“毫秒”也能处理。其他单位或不明确成绩不自动导入。

权限只限两个网站和当前浏览器会话内的测试关联。无所有网站、剪贴板、历史记录或账号令牌权限。浏览器重启、扩展禁用/重载后，未完成关联需要重新发起。

## 验证与维护

`node --test integrations/hb-helper/tests/*.test.mjs` 运行测试。

当前终局结构依据：Human Benchmark 官方反应测试页面及当前资源 `https://humanbenchmark.com/assets/index-BOhEtgge.js`（2026-10-30 核查）。测试结束条件为 5 次有效测试后 phase=score，页面平均值经过 toFixed() 四舍五入显示；本助手不声称取得未取整的原始均值。

浏览器扩展也是测试设备配置的一部分。始终保持同样的浏览器/助手配置，以便比较成绩。
